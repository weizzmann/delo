# Case & Volume App

Приложение на Flask для формирования дел и томов из документов MSSQL.

Короткая инструкция запуска (локально / dev):

1. Установите зависимости:

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

2. Установите ODBC драйвер SQL Server (MS ODBC Driver for SQL Server) согласно ОС.

3. Задайте переменные окружения:

```bash
export MSSQL_CONNECTION_STRING="mssql+pyodbc://user:pass@server:1433/dbname?driver=ODBC+Driver+17+for+SQL+Server"
export SECRET_KEY="change-me"
export FLASK_ENV=development
```

4. Инициализируйте таблицы для пользователей/отделов/дел/томов:

```bash
python create_tables.py
```

5. (Опционально) Заполните тестовую таблицу `documents` примерами:

```bash
python seed_documents.py
```

6. Запустите приложение:

```bash
python run.py
```
